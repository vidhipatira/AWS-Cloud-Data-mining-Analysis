📊 EV Charging Station Analytics Pipeline (PulseCharge Network)


End‑to‑End Cloud Data Engineering Project — AWS RDS, S3, Glue, Athena, SQL Analytics


🚀 Overview
PulseCharge Network operates fast‑charging EV stations across North America. The business faces challenges such as peak‑hour congestion, under‑utilized suburban chargers, unexpected downtime, and customer churn.
This project builds a complete cloud‑based analytics pipeline to help PulseCharge optimize station availability, dynamic pricing, and maintenance operations.
